# Коллекция сценариев и модулей для Sprut.hub

Этот репозиторий содержит набор пользовательских сценариев, глобальных модулей и полезных утилит для платформы умного дома **Sprut.hub**. 

Здесь собраны решения, которые автоматизируют рутину, добавляют недостающую функциональность и делают систему умного дома более отказоустойчивой.

## 🚀 Доступные сценарии и модули

1. 📨 Sprut Message TG over Relay

Глобальный модуль для надежной отправки сообщений в Telegram.

Проблема: Встроенный объект Notify в глобальных сценариях часто работает нестабильно или вовсе недоступен.

Решение: Отправка через промежуточный шлюз (relay) или напрямую через Telegram Bot API с поддержкой резервных серверов, повторных попыток (retry) и API-ключей.

Использование: Идеально подходит как «фундамент» для любых других сценариев, которым нужно отправлять уведомления.

2. 📡 Offline Devices Monitor

Сценарий мониторинга устройств не в сети.

Проблема: Устройства могут терять связь с хабом (Zigbee, Wi-Fi), и вы узнаете об этом слишком поздно.

Решение: Раз в сутки (или с другой периодичностью) сканирует все устройства, собирает список тех, кто не в сети, и присылает красивый пронумерованный список в Telegram.

Особенности: Поддерживает гибкую систему исключений (можно игнорировать конкретные устройства по ID или целые комнаты).

## 🛠 Общие требования и советы по установке

Платформа: Все сценарии написаны для Sprut.hub (Nashorn JS / ES5).

Резервное копирование: Перед установкой новых сценариев всегда делайте бэкап конфигурации хаба.

Проверка ID: Некоторые сценарии (например, мониторинг) используют внутренние ID устройств. Их можно узнать в логах или в интерфейсе хаба.

Токены и ключи: Никогда не выкладывайте в публичные репозитории свои реальные токены Telegram-ботов или API-ключи. Используйте переменные или локальные файлы конфигурации, которые добавлены в .gitignore.

### Почему такой формат удобен:
1. **Навигация**: Если у вас будет 10 разных сценариев, этот README станет отличной «картой» репозитория. 
2. **Презентация**: В двух словах объясняется, какую *боль* решает каждый сценарий (проблема → решение).
3. **Отсылки к подпапкам**: Ссылки `./sprut-message-tg-over-relay/` будут кликабельными на GitHub, и человек сможет сразу перейти к конкретному скрипту и его документации.
4. **Безопасность**: Отдельный блок про токены убережет новичков от утечки ключей.

Вам останется только создать папки `sprut-message-tg-over-relay` и `offline-devices-monitor`, положить туда ваши `.js` файлы и их локальные README (которые мы писали ранее), и ваш репозиторий будет выглядеть профессионально.
