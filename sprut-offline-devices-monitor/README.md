# Мониторинг устройств не в сети (Sprut.hub)

Сценарий для умного дома на базе **Sprut.hub**, который периодически проверяет статус всех устройств в системе и отправляет список тех, кто потерял связь, в Telegram.

## Возможности
- ⏱ **Автоматическая проверка** по расписанию (раз в 1, 6, 12 или 24 часа).
- 📝 **Гибкая фильтрация** — можно исключать конкретные устройства по ID, по имени или целые комнаты.
- 📊 **Удобный вывод** — устройства нумеруются, сортируются по комнатам и содержат внутренний ID для удобной настройки исключений.
- 📨 **Надежная отправка** — использует собственный шлюз (папка /sprut-message-tg-over-relay) с поддержкой резервных серверов (Relay) и повторных попыток при ошибках.
- 🖐 **Ручной запуск** — можно вызвать проверку в любой момент по кнопке из блочного сценария.

## Установка и настройка

Для работы потребуется два сценария: **Глобальный** (отправка в Telegram) и **Основной** (логика проверки устройств).

### Шаг 1: Глобальный сценарий (Отправка)
1. Создайте новый **Глобальный сценарий** в Sprut.hub.
2. Скопируйте в него код из файла `scenario_global_send.js`.
3. В коде найдите массив `RELAYS`. Убедитесь, что первый релей имеет правильные `url`, `api_key` и `channels`. При необходимости добавьте резервный сервер.
4. Сохраните сценарий.

### Шаг 2: Сценарий проверки (Логика)
1. Создайте новый сценарий (с поддержкой JS-кода).
2. Скопируйте в него код из файла `scenario_offline_check.js`.
3. **Настройте исключения**: найдите в коде массив `DEV_EXCLUDE`. 
   Вы можете добавлять правила по трём сценариям:
   ```javascript
   const DEV_EXCLUDE = [
       // 1. Исключить конкретное устройство по ID
       { room: "Новая комната", device: "Выключатель", device_id: "19" },
       
       // 2. Исключить ВСЕ устройства в комнате (маска *)
       { room: "Прихожая", device: "*", device_id: "" },
       
       // 3. Исключить все устройства с именем "Выключатель" в комнате "Кухня"
       { room: "Кухня", device: "Выключатель", device_id: "" }
   ];
4. Настройте периодичность: в блоке options задается частота проверки (1, 6, 12 или 24 часа). По умолчанию сценарий запускается раз в сутки в полночь. Периодичность можно изменить в настройках сценария после сохранения (появится выпадающий список).

### Шаг 3: Ручной запуск (Опционально)

Если вы хотите проверять устройства по нажатию кнопки:

1. Создайте Блочный сценарий.
2. В условии "Если" оставьте бесконечность (∞).
3. В блоке "Тогда" добавьте "Блок кода" и напишите: global.runNow();
4. Теперь вы можете запускать проверку вручную, нажимая кнопку «Play» (▶) в правом верхнем углу интерфейса блочного сценария.
